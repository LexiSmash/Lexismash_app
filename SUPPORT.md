# Support

- **The app doesn't install, start or work as expected?** Open an Issue with the **App bug report** form (tell us your phone model and Android version).
- **How do I install or update it?** Download the APK from [Releases](https://github.com/LexiSmash/Lexismash_app/releases/latest), or add this repository to [Obtainium](https://github.com/ImranR98/Obtainium) for automatic updates.
- **A problem with the game itself?** Report it in the [LexiSmash community repository](https://github.com/LexiSmash/.github/issues), or from the link at the bottom of every page on [lexismash.it](https://lexismash.it).
- **Anything else:** f.rombaldoni@campus.uniurb.it
