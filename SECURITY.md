# Security Policy

This repository contains the LexiSmash mobile app: a Flutter wrapper that shows [lexismash.it](https://lexismash.it) in a WebView and adds a few native features (sharing, voice recognition, file picking, screen kept on). The app itself stores no accounts, passwords or personal data; signing in and playing happen on the website.

If you find a security problem — for example a way for a web page to abuse the app's JavaScript bridge (`LexiSmashApp`), to open unexpected content inside the app, or to get permissions it shouldn't — please **don't open a public Issue**. Write instead to **f.rombaldoni@campus.uniurb.it** with a short description and the steps to reproduce it. You'll get an answer as soon as possible.

Security problems with the game itself (lexismash.it) can be reported at the same address.
